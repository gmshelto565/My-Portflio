
# Giulia Shelton's Personal Portfolio

## Project Description

This project is a personal portfolio website that introduces me,
shares my educational and professional background, and showcases
my web development work and technical interests.

The website uses a feminine pink-and-white design to combine
creativity with a professional presentation of my goals in technology.

## Pages

- `index.html` - Home page and introduction
- `about.html` - Personal background and professional goals
- `projects.html` - Projects and technical learning examples
- `resume.html` - Education, work experience, and technical skills

## Technologies Used

- HTML5
- Flexbox
- CSS 
- Responsive media queries
- Git and GitHub

## Accessibility

- Semantic HTML structure
- Descriptive navigation links
- Logical heading hierarchy
- Readable color contrast
- Keyboard focus indicators
- Responsive layouts for different screen sizes
